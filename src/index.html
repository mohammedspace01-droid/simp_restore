GET STARTED & USE RESPONSIBLY

Simple by design.

Everything runs locally. Here is how to create the backup and what this project is — and is not — intended to do.

01▣

Create a SimpMusic backup

On your phone, open SimpMusic → Settings → scroll to Backup → choose Backup Your Data / Save all your Playlist data. Wording may vary by version.

If available, enable Backup downloaded data so cached media is included.
02⇧

Move the backup to Windows

Transfer the resulting .backup file by USB, LocalSend, or another method. Choose the file as-is; SimpRestore understands the ZIP-compatible archive.

Do not rename individual EXO pieces or edit the original backup.
03▱

Choose one library folder

Use the same destination every time. The local manifest identifies tracks that were already processed, so later backups can add new IDs without repeating the whole collection.

Example: D:\Music\SimpRestore Library
04♫

Restore and play

Recovery rejoins available cache pieces, looks up track metadata, and optionally converts compatible media to MP3. You can also add any local music folder to the player.

Missing or evicted cache pieces cannot be recreated from playlist metadata alone.

02

Choose the .backup file and a library folder. Reuse that same folder for future backups.

03

Let recovery finish. Large backups may take several minutes; progress will update during extraction and conversion.
